# `src` edit guide

- Edit screen layout in `src/screens/LoginScreen.tsx`
- Edit reusable UI pieces in `src/components/`
- Edit text content in `src/constants/loginContent.ts`
- Edit colors in `src/theme/colors.ts`
- Edit spacing and shape tokens in `src/theme/spacing.ts` and `src/theme/shape.ts`
- Replace mock auth calls in `src/services/authService.ts`
- Replace mock login content loading in `src/services/loginContentService.ts`
- Add future screen assets in `src/assets/images/`
